# Module 03 drills (cold, timed, no notes)

1. (60s) `apt install foo` fails with "held broken packages". First command? What does an empty result mean?
2. (60s) Same failure on Rocky: "filtered out by exclude filtering". Which file do you read, and what does its header comment give you?
3. (45s) `dpkg -S /bin/ls` finds nothing but `/bin/ls` runs. Why, and what command fixes the query?
4. (60s) You need who held a package and when. Why is /var/lib/dpkg/status the wrong place? Name the right one.
5. (90s) A dnf lock is on package A. Upgrading B fails. Which command proves B pins A with an exact version?
